# Hospital Priority Queue System

Sistema de gerenciamento de fila hospitalar com Heap de Prioridade implementado em Java.

**Autores:** Gustavo Henrick Rodrigues da Silva e Matheus Fraga Baptistucci

## Como Executar

### PowerShell (Recomendado)

Execute o script PowerShell:

```powershell
.\executar-simples.ps1
```

Ou use o script completo com menu:

```powershell
.\executar.ps1
```

### Manual

#### Compilar

```bash
javac *.java
```

#### Executar Interface Gráfica

```bash
java SistemaHospital
```

#### Executar Teste

```bash
java TesteHospital
```

## Se Java não estiver no PATH

Use o caminho completo do java.exe:

```powershell
& "C:\Program Files\Java\jdk-XX\bin\java.exe" SistemaHospital
```
